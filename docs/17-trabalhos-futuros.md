# 17 - Trabalhos Futuros

## 17.1 Expansão das Funcionalidades

Apesar de funcional, o **AnonProtect** possui um vasto campo para evolução:

- **Refinamento de NLP**: Treinar ou ajustar modelos de linguagem específicos para o contexto jurídico brasileiro, visando maior precisão na detecção de crimes específicos.
- **Sistema de Incentivos Anônimos**: Implementar um sistema de recompensas via criptoativos para incentivar denúncias legítimas, mantendo o anonimato total do denunciante.
- **Aplicativo Mobile Nativo**: Desenvolver uma versão mobile utilizando React Native para aumentar a acessibilidade e permitir o envio de denúncias com localização e mídias em tempo real.
- **Blockchain para Auditabilidade Máxima**: Evoluir os logs de auditoria para uma rede blockchain privada, garantindo a imutabilidade absoluta de cada interação administrativa.
- **Relatórios de Transparência Automatizados**: Geração de PDFs anuais de conformidade LGPD e impacto social para publicação automática no Portal da Transparência.
