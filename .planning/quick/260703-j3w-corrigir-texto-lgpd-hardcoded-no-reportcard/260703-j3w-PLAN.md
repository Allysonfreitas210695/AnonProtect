<objective>
Bugs descobertos durante teste manual E2E completo do fluxo (denúncia pública → tracking → admin) via Playwright, realizado para gerar screenshots do TCC.

Bug 1: `ReportCard` (`src/_components/shared/report-card.tsx`) tinha o texto "PROJETADO PELA LGPD" hardcoded em português (typo — deveria ser "PROTEGIDO") e os botões "Ver Originais"/"Ocultar Originais" também hardcoded, violando a regra de i18n do projeto (CLAUDE.md: "Qualquer texto visível ao usuário precisa estar nos três arquivos messages/\*.json").

Bug 2: Na página de detalhe da denúncia no admin (`/admin/report/[id]`), o botão "Voltar" usava o `Link` localizado de `@/i18n/navigation` (que já prefixa a rota com o locale automaticamente) mas passava `href={`/${locale}/admin/report`}` — prefixando o locale manualmente também. Resultado: URL `/pt-BR/pt-BR/admin/report` e página 404.

Output: Textos i18n corrigidos e adicionados aos 3 locales; link corrigido para usar o padrão já usado no resto do app (`href="/admin/report"`, sem locale manual).
</objective>
