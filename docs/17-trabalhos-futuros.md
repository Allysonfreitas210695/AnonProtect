# 17 - Trabalhos Futuros

## 17.1 Expansão das Funcionalidades

Apesar de funcional, o **AnonProtect** possui um vasto campo para evolução:

- **Implementação de Inteligência Artificial**: Integrar modelos de linguagem (LLMs) para realizar a análise de sentimentos e triagem automática de denúncias, sugerindo níveis de prioridade com base na gravidade do relato.
- **Módulo de Evidências Avançado**: Finalizar a integração de upload de arquivos com armazenamento em nuvem (S3/GCP Storage) e verificação automática de integridade de arquivos.
- **Aplicativo Mobile Nativo**: Desenvolver uma versão mobile utilizando React Native para aumentar a acessibilidade e permitir o envio de denúncias com localização e mídias em tempo real.
- **Relatórios Estatísticos Automatizados**: Sistema de geração de PDFs periódicos para a diretoria, com métricas de tempo médio de resposta e principais focos de ocorrência por departamento.
- **Blockchain para Auditabilidade**: Explorar o uso de logs em blockchain para garantir que nenhuma denúncia seja apagada ou alterada após a submissão, elevando o nível de confiança na auditoria do sistema.
