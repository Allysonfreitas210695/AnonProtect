<threat_model>

## Trust Boundaries

| Boundary                        | Description                                                        |
| ------------------------------- | ------------------------------------------------------------------ |
| browser anônimo → /register     | usuário não autenticado tenta criar conta via página               |
| cliente → registerAction (POST) | chamada direta à server action, ignorando a UI                     |
| Google OAuth → signIn callback  | provedor externo retorna identidade; sistema decide se cria sessão |

## STRIDE Threat Register

| Threat ID | Category               | Component                                     | Disposition | Mitigation Plan                                                                                   |
| --------- | ---------------------- | --------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| T-02-01   | Elevation of Privilege | register.action.ts (hardcoda role SUPERVISOR) | mitigate    | Substituir corpo por `throw new ActionError('Registro desabilitado')` — defesa contra POST direto |
| T-02-02   | Elevation of Privilege | /register route                               | mitigate    | Redirect no proxy.ts antes do handler; remover de isPublicRoute                                   |
| T-02-03   | Spoofing/EoP           | Google OAuth auto-criação                     | mitigate    | signIn callback faz findUnique por email e retorna false para email não cadastrado                |
| T-02-04   | Information Disclosure | mensagem de erro de registro                  | accept      | Mensagem genérica 'Registro desabilitado' não vaza detalhes; baixo valor                          |
| T-02-SC   | Tampering              | npm/pip/cargo installs                        | mitigate    | Nenhum pacote novo instalado nesta fase (RESEARCH Package Legitimacy Audit: none)                 |
