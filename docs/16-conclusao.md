# 16 - Conclusão

## 16.1 Considerações Finais

O desenvolvimento do sistema **AnonProtect** atingiu seu objetivo primordial de fornecer uma plataforma segura, anônima e funcional para o reporte de irregularidades. A integração de tecnologias modernas como **Next.js**, **Auth.js** e **Prisma** permitiu a construção de um sistema que equilibra a complexidade técnica de segurança com uma interface de usuário simples e intuitiva.

## 16.2 Contribuições do Projeto

O projeto contribui para a área de segurança da informação e ética organizacional ao demonstrar que é possível construir sistemas de alta confiabilidade utilizando ferramentas open-source e padrões de desenvolvimento ágeis. A arquitetura baseada em **Server Actions** e **React Server Components** provou ser uma escolha acertada para garantir que a lógica de negócio permaneça protegida, enquanto a internacionalização nativa torna o sistema apto para diversas realidades institucionais.

## 16.3 Impacto Esperado

Espera-se que o AnonProtect sirva como um modelo para instituições que buscam modernizar seus canais de denúncia, promovendo ambientes mais saudáveis, transparentes e justos. A facilidade de rastreio através de códigos únicos, sem a necessidade de identificação pessoal, remove a principal barreira para o combate ao bullying e à corrupção: o medo.
